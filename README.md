## 🚀 Installation & Setup

To run the project locally, follow these steps:

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/your-username/your-portfolio.git
cd your-portfolio
```

### 2️⃣ Install Dependencies
If you are using **Tailwind CLI**, ensure you have **Node.js** installed, then run:
```sh
npm install
```

### 3️⃣ Start Development Server
```sh
npm run dev
```
or if using `live-server`:
```sh
npx live-server
```

## 🎨 Customization

To modify the design:

1. Open `index.html`, `styles.css`, or any component file.
2. Customize Tailwind classes directly in the HTML.
3. Update the **`tailwind.config.js`** file to add custom colors, fonts, or themes.

Example of extending Tailwind:
```js
module.exports = {
  theme: {
    extend: {
      colors: {
        customBlue: "#1E40AF",
      },
    },
  },
};
```
